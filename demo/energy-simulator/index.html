    How it works
    PRODUCTION CONCEPT → PUBLIC IMPLEMENTATION
    01 / Ingest
    Production accepts documents for asynchronous processing. Here: local format, signature and size checks.
    02 / Extract
    Production combines document text, OCR and LLMs. Here: a replaceable mock extractor with a synthetic fixture.
    03 / Validate & review
    Allowlisted fields, explicit missing values and normalization. A human checks inputs before simulation.
    04 / Simulate
    A separate deterministic engine turns period consumption and power into comparable scenario breakdowns.
    

    This is a simplified public demo based on a private production system. Tariffs, prices and sample data are synthetic and do not represent commercial offers.
    The production implementation includes additional validation, pricing rules, integrations and commercial logic intentionally excluded from this demo.
